# README graphics

The shipping README uses [the light header](01-header-light.png). The enforce v3
illustration shipped with the 2026-09-12 release and was retired on 2026-09-27; the
README now shows a still from the /duo launch film instead (`../2026-09-27/`). All images are conceptual illustrations, not certification or
screenshots of generated applications.

The dark header and context-benefit illustration remain optional alternatives.
Previous enforce images remain revision history. Only the selected two assets
are packaged. Generation prompts and image dimensions/hashes are retained in
`prompts.json`, `enforce-v3-prompt.json` and `manifest.json`.
